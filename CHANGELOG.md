# Changelog

All notable changes to the TickTick integration for Gladys Assistant.

## [Unreleased]

### Added

- An **Add task** button on the "TickTick tasks" widget: type a title, pick
  a due day (today or tomorrow), a priority and a list, and the task is
  created in TickTick. Gladys 5.2.0 or later is now required.

## [0.1.1] - 2026-10-09

### Added

- First release: connect your TickTick account (TickTick app and **Connect**
  button), see your overdue and today tasks on a
  "TickTick tasks" dashboard widget, create tasks and list them from scenes,
  and start a scene when a task is due.
- The widget is translated into English and French.
- Requires Gladys 5.1.0 or later.
